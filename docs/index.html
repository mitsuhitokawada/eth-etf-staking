この期間に何が起きていたか

数字はこのページのデータから計算したもの（ETFは百万ドル、ステーキングはETH）。出来事は一般に知られている範囲のもので、どちらが原因かは言えません。「同じ時期に、両方がどう動いたか」の並置です。

2024年7月〜10月：ETFが始まった。最初の4ヶ月は差し引きで流出

米国の現物ETH ETFは2024年7月23日に取引開始。初日は+106.6Mでしたが、その後はGrayscale ETHE（手数料2.5%）からの解約が続き、7月は−484M。10月末までの累計は−481Mと、始まってから4ヶ月はお金が出ていく側でした。いっぽうステーキングは、7月+41万ETH、8月+17万、9月+24万、10月+18万と、淡々と入り続けています。ETFの出入りとは無関係に、ステーキングは増えていた時期です。

2024年11月〜2025年2月：ETFに大きく流入、ステーキングは4ヶ月連続で流出

11月の米大統領選のあと、ETFの流れが変わります。11月+1,057M、12月+2,084M（12月5日の+428.5Mが当時の最大）。この4ヶ月の合計は+3,303M。ところが同じ4ヶ月、ステーキングは−32万、−53万、−29万、−20万ETHと、合計で−135万ETH流出しています。価格が上がった局面で、ETFには買いが入り、ステーキングからは引き出しが増えた。方向が逆だった時期です。

2025年3月〜5月：どちらも停滞

ETFは3月−389M、4月+66M、5月+564M。ステーキングは3月+46万、4月−16万、5月+19万ETH。この時期にEthereumのPectraアップグレード（2025年5月7日）があり、バリデータの最大有効残高が32ETHから2,048ETHに引き上げられました。参考にした解説レポートによれば、これによって大口のステーキングが運用しやすくなり、ETFにステーキングを組み込む議論の下地になりました。

2025年6月〜8月：両方が同時に過去最大の流入

ここがこのページのいちばんの見どころです。ETFは6月+1,165M、7月+5,431M、8月+3,872Mで、3ヶ月合計+10,468M。全期間累計（+13,549M）の8割近くがこの3ヶ月に集中しています。最大の1日は2025年8月11日の+1,018.8M。同じ3ヶ月、ステーキングも6月+101万、7月+56万、8月+40万ETH、合計+197万ETHの流入でした。「ETFに入るとステーキングが減る」のではなく、この局面では両方に同時にETHが向かっています。

2025年9月〜11月：ETFの勢いが止まり、ステーキングは出入りが激しく

ETFは9月+286M、10月+570M、11月−1,424M。11月は全期間で最大の月間流出で、11月13日と20日はそれぞれ−260M前後。ステーキングは9月−70万、10月+123万、11月−89万ETHと振れ幅が大きく、10月8日には1日で+91万ETHという極端な値があります（元データのまま載せていますが、1日でこれだけ動くのは集計上の特殊要因の可能性があるので、そのまま「需要」と読まないほうが安全です）。

2025年12月〜2026年2月：ETFは細く流出、ステーキングは1月に大量流入

ETFは−616M、−343M、−370Mと3ヶ月続けて流出。いっぽうステーキングは2026年1月に+388万ETHと、全期間で最大の月間流入になりました。1月29日の+53万ETHが最大ですが、上位3日を除いても+267万ETHあり、特定の1日ではなく月を通して入っています。ETFから資金が抜けている時期に、オンチェーンではステーキングが増えていた、という逆方向の時期です。

2026年3月〜9月：ステーキング型ETF（ETHB）の登場

2026年3月11日から、Farsideの表にETHBの列が加わります。これはステーキング報酬を組み込むタイプのETFで、それまでの現物ETF（ETHAなど）にはステーキング機能がありません。3月11日以降の累計は、ETHBが+850.5M、ETHA（BlackRock）が+1,155.1M、全体で+1,929.4M。ETHBは新しい商品としては大きな比率で、ETFの資金がステーキングつきの商品に向かい始めた期間と言えます。同じ期間のステーキングは+222万ETHの流入。8月はETF+1,852Mと今年最大の月間流入で、ステーキングは+5万ETHと横ばい、9月はETF+457Mに対してステーキング−37万ETHでした。

全体として

週ごとの数字でETFとステーキングの相関を取ると0.05前後で、統計的にはほぼ無関係です。同じ方向に動いた時期（2025年夏）もあれば、逆に動いた時期（2024年冬、2026年1月）もあります。ETFの流入は「ドルで買われたETHが発行体の保管に入る」動き、ステーキングは「持っているETHをロックする」動きで、動機が違うので当然でもあります。今後、ETHBのようなステーキング型ETFが主流になると、ETFへの流入がそのままステーキングの増加につながる構造になり、この2枚のグラフの関係は変わるかもしれません。それを見るための土台がこのページです。
